# docs/ — index

Navigation map for PleaNP's documentation tree. These files are the
human-readable face of the project's reasoning: the rung ladder, the gate
architecture, the decision history, the audits, and the frozen statement
specs. If you are not sure where a thing lives, start here.

**Start points:** new agent → [`AGENT_HANDOFF.md`](./AGENT_HANDOFF.md) ·
new reader → [`../README.md`](../README.md) · new-contributor intake →
[`CONTRIBUTIONS.md`](./CONTRIBUTIONS.md) · decision history →
[`decisions/LOG.md`](./decisions/LOG.md)
